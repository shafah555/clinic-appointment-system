# User stories

- As a visitor, I want to view doctors so I can find a suitable specialization.
- As a patient, I want to submit an appointment request so I can request a consultation.
- As a patient, I want duplicate time slots to be rejected so the same doctor is not double-booked.
- As a clinic staff member, I want to update appointment status so the schedule remains current.
- As a staff member, I want to generate a demo invoice so consultation charges can be recorded.
- As a patient, I want to view notifications so I can see appointment updates.
- As an administrator, I want to view appointment records so I can monitor the demonstration system.
